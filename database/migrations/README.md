application domain schema — applied via [dbmate](https://github.com/amacneil/dbmate)
(`docker compose run --rm migrate up`, wrapped by `scripts/db-migrate.sh`).

[docs/architecture/database-architecture.md](../../docs/architecture/database-architecture.md)

`database/schema.sql`, alongside this directory, is a dbmate-generated
plain-SQL snapshot of the current schema — regenerated by every
`scripts/db-migrate.sh` run, committed to git as a reviewable-in-diff
reference (not a backup mechanism — see database-architecture.md's
backup/restore section for that).

Applied as the `migrator` role — never the Postgres superuser, never the
runtime application role. See `database/bootstrap/README.md` for how
`migrator` itself is created.
